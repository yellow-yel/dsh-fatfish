### 六包 tarball 指纹（2026-10-31 实测，发布前基准）

发布口径以这张表为准；发完 npm 后用 `npm view <包>@<版本> dist.tarball` 下载回来比对，sha1 必须逐字一致。

| 包 | 版本 | 文件数 | 体积（字节） | SHA-1 |
| --- | --- | --- | --- | --- |
| `dsh-fatfish` | 0.5.0 | 17 | 34155 | `15db92a04921d6a73afb9c7da23709869993ad21` |
| `dsh-fatfish-hands` | 0.1.3 | 12 | 24716 | `619d6f1da677f9d719dd0d76435abbcb14b637b9` |
| `dsh-quota-guard` | 0.1.3 | 15 | 25042 | `6513c99098dba6be59871534185c5b482bd05862` |

| `dsh-fatfish-suite` | 0.1.0 | 7 | 10082 | `5adc0022569b067acbddbcc16e83cbe24286b2f6` |

- 算法与取法：`sha1sum dist\<包>-<版本>.tgz`（Git Bash），文件数取 `tar -tzf` 去掉目录项后的条数；上表六个数字与 `发npm.bat` 要发的六个文件一一对应。
- `dist/` 里还留着 `dsh-path-healer-0.1.0.tgz`、`dsh-batch-doctor-0.1.0.tgz` 两份**旧号占位残留**（0.1.0 已被 npm 占用，不能再发）。按文件名+版本号发，别用通配 `*.tgz`，否则会撞上旧包。
- **`signatures.json` 不是包签名**：它是插件自己的病毒库（挖矿 / RAT 进程名单）订阅源，只用于查毒更新，任何文档和脚本都不要把它当完整性校验凭据；校验凭据只认上表的 sha1。
- 本轮**没有发 npm**：等一次性 6 位动态码，由统筹会话统一发。

踩过的坑，下次发版注意：

- npm 令牌如果勾了「绕过 2FA」，发布会先进待批准队列（`0.0.0-stage` 占位），几分钟后才落地；同一版本号在这个窗口内重复发布会 409 `Cannot publish over previously staged version`。2026-10-30 实测：`npm publish` 立刻返回 `+ pkg@0.1.0`，`npm view` 先看到 `0.0.0-stage`，约几分钟后 `versions` 和 `dist-tags.latest` 才变成 `0.1.0`，此时不用再发，等就行。
- 这种令牌也**不能**撤回已发布内容（403），所以版本号只能往前走，别在占住号上重发。
- 想直接发布、不排队：令牌不要勾「绕过 2FA」，发布时用 `--otp` 传入验证器 6 位码。现在 `.npmrc` 里就是这种令牌，`发布到npm.bat` 会提示输入动态码。
- 2026-10-28 已轮换 npm 令牌：聊天里泄露的旧令牌已从账号删除，新令牌只存在本地 `.npmrc`。
- 2026-10-30 发布两包时又用了一次聊天里给的绕过 2FA 令牌，只写进临时 `.npmrc.verify`（用完即删），长期 `.npmrc` 没动；这个令牌已按泄露处理，发完必须去 npm 后台撤销并重新生成。

## 十、四项仍未验证的真实链路

这四条不是缺陷，是「离线测不到、必须主人在场才能验」的真实链路：要真机、真账号、真鼠标事件或真 Explorer 双击环境，自动化跑不到。等主人在电脑前一条一条过。

| 待验证 | 为什么离线测不了 | 怎么验 |
| --- | --- | --- |
| 真机 NapCat 收发 | 需要一个真在跑的 NapCat 实例和真 QQ 号；本机测到的只是 HTTP 契约与签名校验 | QQ 里给机器人发一句话，看能否收到回复；顺带确认配了 `ONEBOT_ACCESS_TOKEN` 后，不带 token 的请求被拒 |
| B 站真实评论 | 评论区依赖登录态页面 DOM，无头 / 无账号环境取不到 | 打开一个有评论的视频页，让插件读一次评论，核对条数与内容 |
| 气泡真实拖拽 / 点击 | 拖拽与点击要真实鼠标事件和前台窗口，合成事件测不出窗口管理器的行为 | 桌面上按住气泡拖动、点一下，看是否跟手、是否抢焦点、点击响应是否正常 |
| 启动器双击静默运行 | `.bat` + `.pyw` 静默与否取决于真实 Explorer 双击环境，从终端启动走的是另一条路 | 在资源管理器里双击 `启动.bat`，确认窗口正常、没有控制台黑窗；报错时用 `启动-看日志.bat` 能看到堆栈 |
