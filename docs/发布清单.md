踩过的坑，下次发版注意：

- npm 令牌如果勾了「绕过 2FA」，发布会先进待批准队列（`0.0.0-stage` 占位），几分钟后才落地；同一版本号在这个窗口内重复发布会 409 `Cannot publish over previously staged version`。
- 这种令牌也**不能**撤回已发布内容（403），所以版本号只能往前走，别在占住号上重发。
- 想直接发布、不排队：令牌不要勾「绕过 2FA」，发布时用 `--otp` 传入验证器 6 位码。现在 `.npmrc` 里就是这种令牌，`发布到npm.bat` 会提示输入动态码。
- 2026-10-28 已轮换 npm 令牌：聊天里泄露的旧令牌已从账号删除，新令牌只存在本地 `.npmrc`。
- GitHub 的 `github.com:443` 时常被掐，`api.github.com` 反而稳定；git push 失败时改用 Git Data API 写提交、建 tag、建发行版。
