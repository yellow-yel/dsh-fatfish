# 安全说明

## 报告问题

发现安全问题**不要**公开开 issue。用仓库的 GitHub Security Advisories 私下报告，
或直接联系维护者。写清楚：复现步骤、影响版本、可能后果。48 小时内回复。

## 威胁模型

插件跑在**你自己的电脑**上，挂在 DSH 的模型调用链路上。要防的是：

1. **费用失控**：模型调用没有上限，账单或者免费额度被悄悄用光；
2. **账号泄漏**：多账号池把 Key 写进日志、账本或工具输出；
3. **把免费额度误当免费**：未配置单价的模型被报告成 0 元，主人误以为不花钱；
4. **越界**：插件自己去改模型路由或替主人发请求。

## 硬边界（不依赖提示词）

| 能力 | 限制 | 实现位置 |
| --- | --- | --- |
| 默认限额 | 所有限额默认 `0`（不限），装上不会拦任何请求 | `lib/config.js` |
| 超限姿态 | `block` 在请求离开进程前拒绝；`warn` 只记日志 | `index.js` |
| API Key 读取 | 优先 `apiKeyEnv` 环境变量；内联 `apiKey` 只建议本地试用 | `lib/config.js` |
| Key 回显 | 日志、报告、错误信息都不打印 Key | `index.js` / `lib/adapter.js` |
| 账本位置 | 默认 `$DSH_HOME/llm-guard/usage.json`，原子写入 | `lib/store.js` |
| 网络 | 只有配置过的上游模型地址；没有遥测、没有回传账本 | `lib/adapter.js` |
| 路由 | 只注册 `guard-pool` 提供方，是否切过去由主人改配置决定 | `index.js` |
| 工具 | `llm_guard_report` 只读，不改配置、不发请求 | `index.js` |

插件**不提供**的能力：读取任意文件、执行 shell、改系统设置、读取剪贴板、发送消息、
自动购买额度或充值。

## 数据落在哪

| 内容 | 路径 |
| --- | --- |
| 用量账本 | `$DSH_HOME/llm-guard/usage.json`（默认 `~/.dsh/llm-guard/usage.json`） |
| 损坏账本备份 | 同目录 `usage.json.corrupt` |
| 配置（含可选上游账号） | DSH 用户层 `cordis.patch.yml` |

账本只记模型名、提供方、token 数、耗时与费用估算，不记提示词、回复内容、
账号密码或 API Key。删掉账本目录即清空用量历史。

## 已知限制

- 没有单价表的模型报告 `priced: false`，此时 `costCny` 是 0 但**不代表免费**。
- 限额按本机进程内账本计算；多台机器或多个 profile 各算各的。
- 账号池的冷却与故障切换只覆盖插件看到的 `llm/stream` 调用，宿主直接绕过插件的调用不受管。
- 插件不会自动充值、自动换付费账号；账号池里放什么账号完全由主人决定。
- 建议先用 `warn` 观察一周，再切到 `block`，避免误拦正在跑的长任务。

## 支持版本

只对最新发布版本提供安全修复。
