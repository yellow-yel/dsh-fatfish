# Security

## 能做什么

- 读取文件系统元信息（`stat`、`readdir`）来确认路径是否存在。
- 读写插件配置里指定的一个 JSON 文件（默认 `~/.dsh/path-healer.json`）。
- 写回前把旧文件复制成 `.bak`，写入用临时文件 + rename。

## 不做什么

- 不联网，没有遥测、没有远程配置。
- 不执行任何命令 / 脚本 / 程序。
- 不读取文件内容（只判断文件名和是否存在）。
- 不删除、不移动、不重命名任何文件。
- 不写配置之外的路径。

## 需要注意

- 配置里的 `targets[].dirs` 是用户自己填的，插件会去这些目录里找 marker；
  不会递归进入系统目录做无限扫描。
- `deep: true` 会扫非 C 盘根目录和用户主目录，可能耗时几十秒；扫盘期间只读。
- 如果配置文件本身是坏 JSON，会当成空配置处理，并在第一次写回时把坏文件
  备份成 `.bak`，不会静默丢数据。
