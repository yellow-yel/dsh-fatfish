# 安全说明

## 报告问题

发现安全问题**不要**公开开 issue。用仓库的 GitHub Security Advisories 私下报告，
或直接联系维护者。写清楚：复现步骤、影响版本、可能后果。48 小时内回复。

## 威胁模型

套装本身是**元包**：它不联网、不读聊天、不执行命令、不写文件，只负责把三个同伴插件
挂进 DSH，并提供两个只读工具。真正的能力与风险都在同伴包里，各自有独立的安全说明：

- `dsh-fatfish`：人设、本地记忆、只读查毒；
- `dsh-fatfish-hands`：专用 Edge 上网、只读电脑状态；
- `dsh-quota-guard`：模型用量账本、限额、账号轮换。

套装要防的是**误装带来的权限叠加**：用户以为自己只装了一个聊天插件，实际同时获得了
浏览器操作、电脑状态读取和模型调用记账能力。

## 硬边界

| 能力 | 限制 | 实现位置 |
| --- | --- | --- |
| 套装自身网络 | 完全无网络请求 | `lib/index.js` 只读本地文件 |
| 套装自身写入 | 不写文件、不建目录、不改配置 | `lib/index.js` |
| 状态检查 | 只读 `package.json` 与自己的 `cordis.patch.yml` | `fatfish_suite_status` |
| 说明工具 | 只返回静态文字，不执行任何动作 | `fatfish_suite_guide` |
| 能力来源 | 全部来自三个同伴包，各自的红线独立生效 | 见各包 `SECURITY.md` |
| 重复挂载 | 文档明确「套装与三件套二选一」；自检检查 patch 覆盖关系 | README / 上架自检 |

**不提供**：执行 shell、读任意文件内容、读剪贴板、发消息、改系统设置、下载、支付。

## 数据落在哪

套装自身不落任何数据。同伴包的数据位置：

| 内容 | 路径 |
| --- | --- |
| 记忆与查毒缓存 | `~/.dsh/fatfish/` |
| Edge 配置与截图 | `~/.dsh/fatfish-hands/` |
| 用量账本 | `~/.dsh/llm-guard/usage.json` |
| 配置 | DSH 用户层 `cordis.patch.yml` |

## 安装前请确认

- 你接受「浏览器操作 + 电脑状态读取 + 模型用量记账」这三项能力同时存在；
- 你已经装过其中某个同伴包时，先卸载它，避免重复挂载；
- 额度护栏默认只记账不拦截；要防费用失控，请自己配置 `limits`，先用 `warn` 观察。

## 支持版本

只对最新发布版本提供安全修复。
